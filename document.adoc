== Introduction

This document specifies the UniDPP framework for digital product
passports: a neutral, jurisdiction-agnostic core model on which regional,
sectoral and characteristic requirements operate as independently
governed profiles. The framework is a projection architecture — the
passport is a deterministic, registered and legally cited view of an
event-sourced testimonial record (the governed digital twin), and the
profile is a calibrated lens placed on that record.

[NOTE]
====
Provenance. The authoritative content source of this document is the
UniDPP standards-strategy plan (the UniDPP design framework, 2026-09), which defines the
design invariants, the seam register, the lens model, the profile
architecture, the relationship algebra, the event taxonomy, the
transformation algebra, the capability classes, the twin axis, the
visibility and enumeration-resistance rules, the operating model and the
resilience doctrine normatively restated here. The implementation ground
truth is the UniDPP reference core, the Rust workspace `unidpp-core`;
throughout this document, references to modules of that workspace (for
example `crates/model/src/link.rs`) are informative implementation
references, not normative dependencies.

Licence. This document is made available under the Creative Commons
Attribution 4.0 International licence (CC-BY-4.0). The document stage is
Working draft (ISO stage 20).
====

The document is organized as follows. Clause 5 states the framework
invariants. Clause 6 specifies the profile mechanism. Clause 7 specifies
identity, granularity and the relationship algebra. Clause 8 specifies
the event and lifecycle model. Clause 9 specifies the transformation
algebra. Clause 10 specifies the payload tiers and offline operation.
Clause 11 specifies trust and verification. Clause 12 defines the
conformance classes. Annex A lists negative conformance fixtures.
